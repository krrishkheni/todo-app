# To-do app

A simple to-do list built with plain HTML, CSS and JavaScript. No frameworks.

**Live demo:** https://krrishkheni.github.io/todo-app/

## Features

- Add tasks and mark them as done
- Delete a task
- Filter by All, Active or Done
- Clear all completed tasks at once
- Tasks are saved in the browser with `localStorage`, so they stay after a refresh
- Works on phones and with a keyboard

## What I practised

- Handling form and click events in JavaScript
- Updating the page from a list of data (render function)
- Saving and loading data with `localStorage`
- Basic accessibility: labels, focus styles and 44px touch targets

## Run it locally

Open `index.html` in a browser. Nothing needs to be installed.
